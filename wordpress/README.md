# WordPress 테마 (운영 트랙)

카페24 뉴아우토반 WordPress용 **Classic Custom Theme** 개발 폴더입니다.

- 경로: `wordpress/{slug}/`
- 크몽용 정적 템플릿은 `templates/{slug}/` — **별도 트랙**
- slug **사용자 승인 전** 하위 폴더 생성 금지
- Figma부터 여기서 **직접** 테마 구현 (정적 HTML 선행 기본 아님)
- 공지 CPT: `notice` · 메인 최신 **3건**

자세한 내용: [`_docs/wordpress-guide.md`](../_docs/wordpress-guide.md)
