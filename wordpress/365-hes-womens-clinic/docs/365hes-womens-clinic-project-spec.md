## 00. 문서 목적

이 문서는 365헤스여성의원 홈페이지의 기획, 디자인, 개발, 검수 기준을 하나의 원본으로 관리하기 위한 프로젝트 설계서다.

목표는 다음 네 가지를 함께 만족하는 것이다.

```txt
1. 환자가 필요한 진료 정보를 빠르게 찾을 수 있을 것
2. 365일 진료와 전원 여의사 3인의 신뢰가 분명하게 전달될 것
3. 전화·카카오톡·온라인 접수로 자연스럽게 연결될 것
4. 의료광고·개인정보·운영상 위험을 줄일 것
```

이 문서는 법률 또는 의료 자문서가 아니다.  
진료 범위, 의료진 경력, 응급진료 표현, 분만·난임·수술 관련 정보는 실제 병원 확인과 최종 승인을 거쳐야 한다.

# 01. 프로젝트 개요

## 01-1. 기본 정보

```txt
병원명: 365헤스여성의원
업종: 산부인과 / 여성의원
위치: 서초역 인근
운영 특징: 365일 진료
의료진: 전원 여의사 3명
핵심 진료: 여성질환 중심
확장 진료: 임신, 분만, 난임, 여성수술
예약 방식: 예약 접수형
상담 채널: 전화, 카카오톡, 온라인 접수
주차: 병원 전용 주차 불가
```

## 01-2. 프로젝트 목표

```txt
- 여성질환 중심의 전문성을 첫 화면에서 명확히 전달
- 365일 진료의 실제 편의성을 사용자 관점에서 설명
- 민감한 진료에 대한 불안감을 낮추고 상담 접근성을 높임
- 증상 중심 탐색으로 원하는 진료를 빠르게 찾도록 지원
- 전원 여의사 3인의 전문 분야와 진료 역할을 구분
- 여성질환, 검진, 임신, 난임, 분만, 수술로 확장 가능한 구조 설계
- 서초역 접근성과 대중교통 이용 정보를 명확히 안내
- 접수형 예약 구조를 오해 없이 안내
```

## 01-3. 프로젝트 포지셔닝

### 핵심 포지션

```txt
여성의 일상적인 불편부터

```

### 브랜드 핵심 키워드

```txt

- 질환명이 아니라 환자의 증상과 상황에서 시작하는 진료 탐색
- 여성 생애주기별 건강 흐름

- 실제 이용 정보 중심의 FAQ
- 대중교통 중심 위치 안내
```

# 19. 핵심 요약

```txt
365헤스여성의원은
365일 진료, 전원 여의사 3인, 여성질환 전문성을 중심으로 설계한다.

메인페이지는
오늘 진료 안내 → 증상 탐색 → 대표 진료 → 생애주기 → 의료진
→ 임신·출산 → 검사·수술 시스템 → 공간 → FAQ → 위치·접수
순서로 구성한다.

대표 서브페이지는 여성질환 클리닉으로 설계하고,
이를 기준으로 여성검진, 임신·출산, 난임·가임력, 여성수술 페이지를 확장한다.

응급실, 난임 시술, 분만, 수술 범위는 실제 확인 전 확정 표현을 사용하지 않는다.
온라인 예약은 접수형이며 병원 확인 후 최종 확정된다.
```
