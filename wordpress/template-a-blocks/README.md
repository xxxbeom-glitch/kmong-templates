## Template A Blocks (블록 테마 · 메인 1차)

### 쓰는 법
1. 테마 **Template A Blocks** 활성화
2. **설정 → 읽기** → 홈페이지 표시 = 정적인 페이지 → 전면 페이지 지정
3. 왼쪽 **모양 → 편집기** (또는 **디자인**)
4. 헤더 / 홈 템플릿 / 푸터를 클릭해 글·이미지 수정 후 저장

### 범위 (1차)
- 메인(홈): 히어로 · 인트로 · 특징 4카드 · CTA
- 헤더 · 푸터 템플릿 파트

### 아직 없음
- 서브 페이지 풀 디자인 (회사소개, 서비스 등)
- 클래식 Template A와 동일한 인터랙션 전부

클래식 테마 `template-a`는 그대로 유지됩니다.
