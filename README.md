| 경로 | 역할 |
|------|------|
| `wordpress/{slug}/` | 테마 작업 · ZIP 납품 |
| `.cursor/rules/` | Cursor 규칙 |
| `.cursor/sot/` | 제작 SoT (컨텍스트·토큰·WP 지침) |
| `.cursor/business/` | 사업 검증 문서 |
| `_docs/active-track.md` | 지금 트랙 1장 |
| `_icons/` | 아이콘 원본 (테마로 복사) |
| `_archive/` | 동결·흡수 완료 원본 |

현황: `_docs/active-track.md`
