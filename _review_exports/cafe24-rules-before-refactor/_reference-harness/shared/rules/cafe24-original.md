# Cafe24 Original — ZIP vs Demo

> `80`~`82`와 연계. harness 안에서 original 등급을 섞지 않는다.

## A. 정식 구매·보유 스킨 ZIP / 원본 파일

- 스킨 전체 → `01-original` (`originalCompleteness: skin-zip`)
- checksum · file inventory
- ZIP ↔ local original 비교 (02-original-qa)
- module / variable / layout directive / form name·action inventory
- original PASS 후 working-copy
- 복사본에서만 수정 · module·변수·form·hidden **유지**

## B. 공개 데모 URL만

- 브라우저가 받은 HTML/CSS/JS/정적 자산만 (`browser-captured`)
- 판매 스킨 전체 보유로 **표시·취급 금지**
- 내부 분석·비교 전용
- 상업 작업 전 **정식 구매 스킨** 필요
- 데모 이미지·폰트·배지·코드 무단 납품 금지
