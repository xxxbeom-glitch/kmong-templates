## 2. 모자란 것 (디자인·개발)

### 2-1. 문서·규칙 운영

1. **짧은 “하루 루프” 카드 없음**  
   디자이너(비개발) + Cursor가 매일 볼 5~7줄 절차가 없음.  
   예: `수정 범위 확정 → 방향 1장 → 구현 → 브라우저+관리자 QA → PASS`  
   지금 절차는 `20-harness` + TRANSITION §2 + SUBPAGE 등으로 **분산·두꺼움**.

2. **Design Director 미연결**  
   `CURSOR_UIUX_DESIGN_DIRECTOR(1).mdc`가 루트에 있고 alwaysApply 성격이 강한데, `.cursor/rules/`에 정식 편입·역할 분담(디렉터 vs `30` 피그마 vs `50` QA)이 안 됨.  
   → **과적용(매 요청 전체 QA)** 또는 **무시** 위험이 큼.

3. **SoT 과다·중복**  
   CONTEXT §3 ≈ do-dont ≈ Director 일부.  
   `wordpress-subpage-system.md` ≈ SUBPAGE.  
   `design-do-dont (1).md` = `design-do-dont.md` **완전 동일 파일**(정리만 하면 됨).  
   → “무엇을 읽고 무엇을 무시해도 되는지” **단일 인덱스**가 약함.

4. **decision-log 히스토리 혼선**  
   맨 위 “유효 결정”은 WP인데, 아래 과거 섹션에 “정적 활성·WP 동결”이 남아 있음.  
   에이전트가 과거를 현재로 읽을 여지.

### 2-2. 디자인 시스템

5. **그림자 SoT** — **해소(A~F E):** 기본=중립 alpha · 컬러=제한적. tokens 주석·CONTEXT 동기화됨.

6. **카드·보더 취향 vs 토큰**  
   do-dont ★: 카드에 border 금지, 그림자/배경으로 구분.  
   토큰에는 border 유틸이 풍부.  
   → “카드 UI만 ★ 적용 / 인풋·표는 예외”는 문서에 있으나, **컴포넌트별 예시(카드·버튼·인풋 1세트)**가 없음.

7. **첫 베이스 테마 / slug 없음**  
   `wordpress/{slug}/` 실제 테마 뼈대가 아직 없음.  
   토큰→CSS 변수 파일·헤더/푸터·공지 CPT 보일러플레이트가 **레포에 고정 샘플로 없음**.

8. **아이콘 운용 절차**  
   `_icons/` 우선은 확정.  
   없는 아이콘일 때: 직접 SVG 추가 vs 승인 후 CDN 1회 vs 텍스트만 — **폴백 절차 미정**.

### 2-3. 워드프레스·프론트 구현

9. **킥오프 깊이 불균형**  
   `70` 기본: 공지 CPT만.  
   `TRANSITION` §2: CPT·권한·플러그인·메일 등 **두꺼운 체크리스트**.  
   → “기본 킥오프 vs 확장 킥오프” 경계 문장이 약함(질문 과다 / 범위 누락 둘 다 가능).

10. **플러그인 표준 = 후보만**  
    Yoast·CF7·W3TC 등 표는 있으나, **소개형 홈+공지+문의** 최소 세트에 뭐가 필수인지 한 표가 없음.

11. **관리자 UX 가이드 템플릿 없음**  
    납품 시 “편집자 안내”는 언급되나, 재사용 가능한 **짧은 고객용 가이드 뼈대**(공지 작성·이미지 비율·글자 수)가 레포에 없음.

12. **실브라우저 QA vs 바이브**  
    `50`/`35`는 뷰포트·실브라우저 요구가 있음.  
    피그마 없이 바이브할 때 **최소 QA 세트**(필수 vs 납품 직전만)가 한곳에 압축돼 있지 않음.

13. **GSAP 패턴 카탈로그 없음**  
    jQuery `46` preset은 동결에 가깝게 둠.  
    WP용 **허용 모션 패턴 목록**(스크롤 리빌, 스태거, 히어로 등)과 섹션당 상한이 GSAP 기준으로는 미작성.

### 2-4. 디자인·개발에 영향 있는 미정(사업이지만 범위 언급만)

14. 시작 **업종** · 첫 **slug** · 포트폴리오에 쓸 **레퍼런스 방향** — 베이스 테마 비주얼·IA에 영향.  
    (가격·패키지 금액은 본 문서 범위 밖.)

## 5. 조언 받고 싶은 질문 (디자인·개발만) — A~F 제외 갱신

ChatGPT에게 그대로 붙여 넣어도 됨. **충돌 A~F는 확정됐으므로 재질문하지 말 것.**

1. SoT를 **최소 몇 개 파일**로 줄이는 구조 제안 (인덱스 1장 + 본문 N).  
2. Design Director를 Cursor 규칙으로 쓸 때 **과적용 방지** 운영법 (alwaysApply? 요청 유형별?).  
3. 첫 `wordpress/{slug}/` 베이스 테마에 **반드시 들어갈 최소 파일·CPT·토큰 CSS** 체크리스트.  
4. GSAP 기준 **허용 모션 카탈로그**를 어느 수준까지 문서화할지 (과한 preset화 vs 원칙만).  
5. do-dont의 ★ 취향(카드 보더 금지, 단독 아웃라인 버튼 금지 등)이 **WP 관리자 편집 콘텐츠**(긴 제목·이미지 없음)와 싸울 때, 규칙 우선순위.  
6. 피그마 없는 QA: **섹션마다** vs **페이지 완성 후** 실브라우저 — 1인 프리랜서 속도 기준 권고.
