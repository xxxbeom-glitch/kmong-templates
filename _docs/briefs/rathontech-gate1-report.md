## 2. Solution / Product / Case / Certification · 새 IA 제안

### 2-1. 역할 구분 (화면·카피)

| 유형 | 사용자에게 답하는 질문 | 반복 금지 |
|------|------------------------|-----------|
| **Solution** | “우리 문제를 어떤 방식으로 풀까?” | 제품 스펙 나열 |
| **Product** | “무엇을 도입·연동하나?” | 솔루션 카피 복붙 |
| **Case Study** | “비슷한 곳에서 뭐가 됐나?” | 추상 마케팅만 |
| **Certification** | “증빙·규정 대응은?” | AI 생성 인증서 |

### 2-2. 관계 모델 (제안 · 미잠금)

```text
Solution ──related──> Product (N)
Product  ──related──> Case Study (N)
Product  ──related──> Certification (N)
Case Study ──uses──> Product (N)
Case Study ──about──> Solution (0~N, taxonomy로도 가능)
```

기획서 §4-3 솔루션↔제품 연결을 1차 관계표로 채택(데이터 확정은 Gate 4).

|----------|---------------------------|
| 통합계정·권한관리 | Rathon-IAM, Rathon-LDAP, IBM-SDS, IBM-SAM |
| 인증 | Rathon-SSO, MFA, WinLogin, Symantec SiteMinder |

**1차 5개 + 헤더 CTA** (개수 하드캡 없음 · 2depth로 그룹핑 — do-dont/A~F D와 정합)

### 2-5. CMS 가설 (선택지만 · **미확정**)

| 옵션 | 내용 | 영향 |
|------|------|------|
| **A. 동반 플러그인 CPT** | Solution/Product/Case/Certification + taxonomy | 테마 교체 안전 · 초기 공수↑ · SoT「CPT 테마 종속 금지」와 가장 정합 |
| **B. 테마 CPT** | functions에 등록 | 빠름 · 테마 종속 리스크 |
| **C. 1차 Page + 구조화 콘텐츠** | 대표 페이지만 Page·부분 하드코딩 | Gate 3 속도↑ · 필터/관계 약함 · 나중에 마이그레이션 |

**Gate 1 권고:** 관계·IA는 A를 전제로 **설계**하되, 코드·플러그인 **확정·구현은 Gate 4**.  
소식/공지 CPT는 본 사이트 핵심이 아님 → 기존 SoT 미결정과 충돌 없음(필수도 아님).

## 4. 디자인 방향 계약 (Gate 2 입력용 · 제안)

SoT: 임의 hex 금지 · IT·신뢰 = **토큰 v1 블루 계열** (`.cursor/sot/01` §4-1) · SUIT · A~F.

### 4-1. 핵심 논제

> **복잡하게 흩어진 계정과 접근을 하나의 신뢰 체계로 연결한다.**

금지 중심 이미지: 자물쇠·방패·후드 해커·파란 네온 서버(기획 §3-4).

### 4-2. Signature Move

- **위치:** 메인 히어로 **한 번만**  
- **내용:** `사용자 → 인증 → 정책 판단 → 업무 시스템 접근` 연결 그래프  
- **모션:** 필요할 때만 GSAP · 자동 루프 금지 · 스크롤 가로채기 금지 · `prefers-reduced-motion` → 정적 · 모바일 노드 축소  
- **입자·가짜 데이터 스트림 금지**

### 4-3. Quiet Zone

- **도입사례 · 인증(및 고객 증거)**  
- 장식↓ · 사실·로고·인증서명·타이포 위계↑ · 넓은 여백

### 4-4. 색·타이포·간격 토큰 (기존 SoT만)

| 역할 | 토큰/값 (제안) |
|------|----------------|
| Primary / CTA | `--blue-600` `#2563EB` 계열 (시멘틱 primary로 매핑) |
| 본문 | `#1A1A1A`~`#333` · 본문 **16** 하한 |
| 배경 | light 정보면 + **제한적** dark 포인트 (네온 과다 금지) |
| 강조 | CTA·활성·연결 흐름에만 (60-30-10) |
| 폰트 | **SUIT** · 굵기 2~3종 |
| 컨테이너 | `--container-max: 1600px` |
| BP | 767 / 1023 / 1024 / 1600 |
| 카드 | padding/gap **24** · border 남발 금지(★) · 그림자 중립 alpha |
| 섹션 구분 | 배경색 강제 아님 · 여백·타이포·배경·이미지 선택 (A~F F) |

새 색상값 **기획서에 추가하지 않음**.

## 6. 미확정 — 선택지와 영향만

### 6-1. CMS (상기 §2-5)

Gate 4 전 코드 확정 금지. IA·관계는 **A안 전제 설계** 권고.

### 6-2. 문의 전송

| 옵션 | 영향 |
|------|------|
| 이메일만 (CF7 등) | 단순 · DB 없음 · 스팸·보관 정책 별도 |
| DB 저장 + 메일 | 운영·보유기간·삭제·암호화 설계 필요 |
| 1차: UI만 · 전송 stub | 디자인 검증 가능 · 완료조건상 “미완” 명시 |

**Gate 1:** 문의 페이지는 구조만 기획 유지 · **문구·서버·CAPTCHA 미잠금**.

### 6-3. 자산 권리

| 옵션 | 영향 |
|------|------|
| 플레이스홀더·다이어그램만 | 안전 · Quiet Zone 설득력↓ |
| 원본 로고·인증·UI (권리 후) | 신뢰↑ · 공개/포트폴리오 시 고지 |
| 비식별·재작성 카피 | 학습 공개에 유리 |

**Gate 1~2:** 히어로는 **SVG/HTML 그래프** · 고객·인증은 Quiet에서 **확인된 텍스트** 우선.
