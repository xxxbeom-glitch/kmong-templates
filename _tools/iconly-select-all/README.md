# Iconly Select All (Chrome)

[web.iconly.pro](https://web.iconly.pro/) 에서 **전체 선택**을 도와주는 로컬 확장입니다.  
Export / Copy SVG는 Iconly 기존 버튼을 그대로 사용합니다.

## 설치 (크롬)

1. 주소창에 `chrome://extensions` 입력
2. 우측 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드합니다**
4. 이 폴더 선택: `_tools/iconly-select-all`
5. [https://web.iconly.pro/](https://web.iconly.pro/) 로그인 후 라이브러리 그리드 열기
6. 오른쪽 위 **Iconly 선택** 패널 사용

## 버튼

| 버튼 | 동작 |
|------|------|
| 화면에 보이는 것 전체 선택 | 현재 보이는 카드만 선택 |
| 스크롤하며 가능한 만큼 선택 | 아래로 넘기며 반복 선택 |
| 선택 해제 | 선택된 카드 다시 클릭 |

선택 후 Iconly 하단 **Export** 또는 **Copy SVG**를 누르세요.

## 참고

- Iconly UI가 바뀌면 카드 인식이 실패할 수 있습니다. 그때 알려주세요.
- 가상 스크롤/페이지네이션이면 한 번에 “진짜 전체”가 안 될 수 있어, 카테고리·검색 범위를 나눠 쓰는 게 안전합니다.
- 본인 구독 계정에서만 사용하세요.
