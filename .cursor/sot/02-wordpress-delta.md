# PROJECT_CONTEXT 변경사항
> **활성 납품:** WordPress ZIP (`70` · `package-delivery-wp.js`)  
> **본 문서:** 하드코딩 → WP 전환 시 PROJECT_CONTEXT 변경분만. 본편과 함께 읽는다.  
> **채택일:** 2026-08-03 · `_docs/active-track.md` 기본 = WordPress

---

## 2-5. 관리자 기능 (변경)

**기존**
> 초기에는 관리자 기능 없이 납품. 콘텐츠 수정은 유지보수 월정액으로 대신 처리.

**변경**
- 워드프레스 관리자가 곧 고객 관리 도구
- 고객이 직접 텍스트, 이미지, 게시글 수정 가능
- 관리자 기능 없이 납품하는 옵션 삭제

---

## 2-3. 기술 스택 (변경)

**기존**
> 코딩 방식: 커스텀 HTML/CSS/JS (WordPress 사용 안 함)

**변경**
- 코딩 방식: 워드프레스 테마 (PHP + HTML/CSS/JS)
- 테마 구조: `functions.php`, `page.php`, `header.php`, `footer.php` 등 워드프레스 표준 파일 구조
- GSAP, 디자인 토큰, 컴포넌트 규칙은 그대로 테마 안에서 사용

---

## 2-7. 수익 구조 (변경)

**기존**
> 유지보수: 월 정액 (콘텐츠 수정, 장애 대응)

**변경**
- 콘텐츠 수정은 고객이 직접 → 유지보수에서 제외
- 유지보수 내용이 기술 관리로 바뀜:
  - 워드프레스 코어 업데이트
  - 플러그인 업데이트
  - 보안 점검
  - 백업 확인
  - 장애 대응
- 단가: 관리자 포함 납품이므로 하드코딩 대비 높게 책정

---

기존 `/cursor-rules/` 에 아래 폴더 추가:

```
    gutenberg.md         ← 블록 에디터 커스터마이징 범위

```
