# 크몽 바이브코딩 웹 프리랜서 프로젝트 컨텍스트

> 이 문서는 커서(Cursor)에게 프로젝트 전체 맥락을 전달하기 위한 문서다.
> 디자인 작업 시 이 문서를 기반으로 판단하고 제안한다.

---

## 1. 이 프로젝트가 뭔가

크몽(kmong.com)에서 중소기업 및 개인사업체를 대상으로 웹사이트를 수주·제작·납품하는 1인 프리랜서 사업이다.

핵심 방식은 바이브코딩이다. AI(Claude, Cursor)를 적극 활용해 기획부터 제작까지 1인이 빠르게 처리한다.

**운영자 강점**
- UI/UX 기획 및 디자인
- 제품 컨셉 설계
- AI 도구 활용

**운영자 현재 수준**
- 바이브코딩으로 웹사이트 1개 제작 경험
- 기본적인 코드 구조 이해
- 디자인 경험 있음, 실제 제작·운영 경험은 초기 단계

## 2. 픽스된 결정 사항

### 2-1. 플랫폼
- **판매 채널**: 크몽 단일 채널로 시작
- **이유**: 이미 가입 완료, 검증된 수요 존재, 진입 비용 없음

### 2-2. 타겟 고객
- **대상**: 중소기업, 개인사업체 (미용실, 음식점, 인테리어, 학원, 제조업 등)
- **제외**: 병원/의원 (의료광고법 규제로 법적 위험 높음)
- **전략**: 업종 하나를 골라 전문가로 포지셔닝, 이후 확장

### 2-3. 기술 스택
- **호스팅**: 카페24 WordPress (고객 명의 계정)
- **도메인**: 카페24 또는 가비아 (고객 명의)
- **코딩 방식**: **워드프레스 커스텀 테마** (PHP + HTML/CSS/JS)
- **테마 구조**: `functions.php`, `page.php`, `header.php`, `footer.php` 등 표준 파일
- **애니메이션**: 모션이 필요할 때 **승인 표준** = GSAP + ScrollTrigger (`45`) — 전 테마 의무 아님
- **슬라이더**: 슬라이더가 필요할 때 **승인 표준** = Swiper.js — 전 테마 의무 아님
- **jQuery**: WP 번들만(필요 시) · `46` jQuery preset은 WP 신규 **기본 금지**(명시 승인 시만)
- **폰트**: SUIT (기본값 · `.cursor/sot/05-design-tokens.md`)
- **컨텐츠 폭**: 1600px (`--container-max`)
- **아이콘 크기**: 토큰 마스터 `--icon-xs`~`--icon-2xl`
- **아이콘**: 레포 **`_icons/`** = 원본 저장소 · 납품 테마는 사용분만 **`assets/icons/`로 복사** · CDN(Lucide/Heroicons) 기본 금지
- **소식/공지 CMS:** WP 기본 글 vs `notice` CPT vs 동반 플러그인 = **미결정** · 확정 전 테마에 임의 구현 금지
- **디자인 토큰·컴포넌트·UIUX 원칙**: 테마 자산 안에서 동일 적용
- **상세 델타:** `.cursor/sot/02-wordpress-delta.md` · `.cursor/sot/03-wordpress-transition.md`  
- **서브페이지:** `.cursor/sot/04-wordpress-subpage.md`

### 2-4. 계정 및 납품 구조
- 호스팅, 도메인 모두 **고객 명의**로 생성
- 작업 시 FTP/관리자 접근권한만 임시 부여받아 작업
- 납품 후 접근권한 반납
- **이유**: 추후 인수인계, 분쟁 방지

### 2-5. 관리자 기능
- **워드프레스 관리자 = 고객 관리 도구**
- 고객이 직접 텍스트·이미지·게시글 수정 가능
- **관리자 없이 납품하는 옵션은 기본에서 삭제**
- 레이아웃·구조 전체 편집(빌더)과 콘텐츠 수정은 구분 (`.cursor/sot/03-wordpress-transition`)

### 2-6. 템플릿 전략
- 베이스 테마를 하나 만들고 업종별로 디자인 변형
- 클라이언트에게는 "업종 맞춤 제작"으로 제공 (이는 사실임)
- "완전히 처음부터 만든다"는 표현은 사용하지 않음
- 외부 판매자 템플릿 클론 금지 (저작권 문제)
- 오픈소스(MIT 라이선스) 레퍼런스는 참고 가능

### 2-7. 수익 구조
- **제작비**: 건당 단가 (관리자 포함 · 하드코딩 대비 높게 책정)
- **유지보수**: 월 정액 — **기술 관리** 중심
  - 워드프레스 코어·플러그인 업데이트
  - 보안 점검 · 백업 확인 · 장애 대응
- **콘텐츠 수정은 고객 직접** → 유지보수에서 제외 (합의된 대행은 별도)
- 패키지 예시:
  - 제작만: 기본가
  - 제작 + 3개월 기술 유지보수: 기본가 + 알파
  - 제작 + 월 유지보수 정기권: 기본가 + 월 정액

### 2-8. AI 활용 워크플로우
```
Claude (기획) → 커서 (테마 제작) → 카페24 WordPress (납품)
```
- 기획서, 요구사항 정리, 컨셉 방향: Claude
- 테마·CPT·관리자 UX·수정: 커서
- 최종 검수 및 납품: 직접

### 2-9. 작업 경로 (레포)
- **활성:** `wordpress/{slug}/`
- **동결:** `templates/` 하드코딩 정적
- SoT: `_docs/active-track.md`

## 3. 커서 작업 규칙

### 3-1. 기본 원칙
- 기획 문서가 들어오면 design-principles 기준으로 먼저 판단
- 지정된 토큰 파일 외 임의 색상 사용 금지
- **설계:** PC·모바일을 함께 본다 · **CSS 구현:** 모바일 퍼스트(`min-width`로 확장)
- 모션이 필요하면 **GSAP만** 사용(다른 모션 라이브러리 혼용 금지) · 불필요하면 넣지 않음

### 3-2. 디자인 원칙

**시각적 위계**
- 한 화면에 시선이 멈추는 곳은 1개만
- 크기 차이는 애매하게 주지 않는다. 확실히 크거나 확실히 작거나
- 제목:본문 크기 비율은 최소 1.5배 이상
- 색상 강조는 전체의 10% 이하
- 볼드는 진짜 중요한 것 1~2곳만

**여백**
- 관련 있는 요소끼리는 가깝게, 관련 없는 요소끼리는 멀게
- 섹션 간격은 요소 간격의 3배 이상
- 버튼 패딩은 상하보다 좌우를 2배로
- 모르면 여백을 더 줘라

**타이포그래피**
- 본문 줄 길이: 45~75자 (모바일 35~50자)
- 줄간격: 본문 1.5~1.7, 제목 1.1~1.3
- 한 페이지 폰트 굵기: 2~3가지만
- 본문 색상: 순수 검정(#000) 사용 금지 → #1A1A1A~#333
- 기본 폰트: SUIT
- **최소 크기 (SoT: `.cursor/sot/05-design-tokens` §2-0)**
  - 본문 PC/MO **16px** · 보조 14px · 캡션 12px · CTA 14px · 제목 20px · input 16px
  - PC에서 본문을 16 미만으로 줄이지 않음

**색상**
- 60-30-10 법칙: 배경(60%) : 보조색(30%) : 강조색(10%)
- CTA 버튼은 페이지에서 가장 눈에 띄는 색 하나만
- 채도 높은 색 한 페이지에 2개 이상 금지
- **그림자:** 중립색(검정/그레이) alpha 기본 허용 · 컬러 그림자는 CTA·브랜드 포인트 등 **제한적** 사용 (`.cursor/sot/05-design-tokens` §5)

### 3-3. 컴포넌트 규칙

**버튼**
- Primary 버튼은 페이지당 1개 원칙
- 비활성 버튼: opacity 40%
- 방향성 아이콘(→)만 오른쪽, 나머지 아이콘은 텍스트 왼쪽

**카드**
- 내부 여백 vs 카드 간 간격의 **대소 관계 강제 없음**
- PC 기본값: `padding 24px` · 카드 간 `gap 24px` (토큰 `--card-padding` / `--card-gap`)
- 카드 안 이미지 비율 전체 통일 (16:9 또는 4:3)
- 카드 호버 시 그림자는 아래로만

**네비게이션**
- 메뉴 개수 **하드 한도 없음** · **6개 이상**이면 그룹핑·우선순위 검토
- 브레드크럼: 계층이 깊거나 상위 이동이 필요할 때만 (`.cursor/sot/04-wordpress-subpage`)
- 스크롤 시 헤더: blur() + 반투명
- 모바일 햄버거: 오른쪽에서 슬라이드인

**폼**
- 라벨은 항상 입력 필드 위에 (placeholder로 대체 금지)
- 오류 메시지: 빨간색 + 아이콘 같이 (색상만으로 표시 금지)
- 필수 항목 대신 선택 항목에 "(선택)" 표기

**모달**
- 배경 dimmed: opacity 0.6~0.7
- 닫기 버튼: 우상단 고정
- 모바일: bottom sheet로 전환

**아코디언**
- 첫 번째 항목 기본 열림 상태
- 아이콘: + / - 또는 ∨ / ∧ 중 하나로 통일

**토스트**
- 3~4초 후 자동 사라짐
- 성공(그린), 오류(레드), 정보(블루) 구분
- 아이콘 + 텍스트 조합 필수

**갤러리**
- 클릭 시 라이트박스 필수
- 모바일: 2컬럼 기본
- 이미지: lazy load 필수

**가격표**
- 3개 플랜이 가장 전환율 높음
- 추천 플랜은 가운데, 시각적으로 부각
- "가장 인기" 배지 필수

### 3-4. 섹션별 패턴

**히어로**
- 메시지 구조: 고객 문제 → 해결책 → CTA
- 높이: 뷰포트 80~100%
- 서브텍스트: 2줄 이하
- 배경 이미지는 분위기용, 텍스트보다 강하면 안 됨

**서비스 소개**
- 3개 또는 6개가 가장 안정적
- 아이콘은 같은 패밀리로만
- 가장 강조할 서비스는 가운데 또는 첫 번째

**신뢰 섹션**
- 숫자는 구체적으로: "다수의 고객" → "127개 기업"
- 후기는 직함 + 이름 있어야 신뢰됨
- 로고 슬라이더는 흑백으로

**CTA 섹션**
- 배경색 바꿔서 섹션 분리
- 문구는 혜택 중심
- 버튼 2개 이상 넣지 않는다

**푸터**
- 사업자 정보 반드시 포함 (한국 법적 의무)
- 배경은 헤더와 같은 색 또는 가장 어둡게

### 3-5. 한국 중소기업 특화 규칙
- 대표 전화번호는 항상 헤더에 노출
- **카카오톡 상담 버튼:** 우하단 플로팅 — **기본은 메인·문의 등 전환 핵심 페이지만**. 전 페이지 강제는 아님 (`.cursor/sot/04-wordpress-subpage` §15 · 방해·safe-area 검토)
- 지도/오시는길 섹션 거의 필수
- 네이버 지도 연동 우선 (구글 지도보다 친숙)
- 공신력 로고(인증, 수상, 협회)는 히어로 바로 아래 띠 형태로

### 3-6. UX 전환율 규칙
- 히어로에서 3초 안에 뭐하는 곳인지 읽혀야 함
- CTA 버튼 문구는 동사로 시작: "문의하기" → "무료 견적 받기"
- 신뢰 요소는 CTA 버튼 바로 위 또는 아래에 배치
- Above the fold에 핵심 메시지와 CTA 필수

### 3-7. 심리적 설계
- 사람 사진에서 인물 시선 방향으로 CTA 배치
- 가격 제시 시 높은 가격 먼저 (앵커링)
- CTA 옆 또는 아래에 사회적 증거 (후기, 별점) 배치

### 3-8. 금지 사항
- 텍스트 본문 가운데 정렬 금지
- 배경 이미지 위 오버레이 없이 텍스트 올리기 금지
- 목적 없는 애니메이션 금지
- 밑줄 없는 파란 텍스트 금지 (링크로 오해)
- 모바일에서 hover 효과 금지
- 라인 아이콘과 필드 아이콘 혼용 금지

## 4. 디자인 시스템

### 4-0. 토큰 SoT
- 마스터: `.cursor/sot/05-design-tokens.md`
- 확정: 폰트 SUIT · 컨테이너 1600 · BP 767/1023/1024/wide1600 · 아이콘 크기 마스터 · `_icons/` 원본 → 테마 `assets/icons/` 복사

### 4-1. 토큰 버전 (시멘틱 primary 조합)
- **v1 (블루 계열)**: 신뢰감, 전문성 → 제조업, IT, 컨설팅
- **v2 (그린/네이비)**: 안정감 → 교육, 건강
- **v3 (다크/모노)**: 고급감 → 인테리어, 프리미엄

### 4-2. 그레이스케일
- 100~900 스케일 하나로 전 버전 공유
- 본문 색상: #1A1A1A~#333 범위

### 4-3. 그림자 시스템
- 기본: 중립색 alpha (`--shadow-xs`~`--shadow-2xl`)
- 용도: sm 카드 · md 드롭다운/모달 · lg 팝업·플로팅
- 컬러 그림자(`--shadow-color-*`): 제한적(포인트·CTA 등) · 전역 기본 아님

### 4-4. 보더 시스템
- 굵기: 1px 기본, 2px 강조
- 색상: gray-200 기본, gray-400 강조
- 라운드: 4px / 8px / 16px / pill 4단계

### 4-5. z-index 체계
```
기본:        0~10
드롭다운:    100
헤더:        200
모달 배경:   300
모달:        400
토스트:      500
```

### 4-6. 반응형 브레이크포인트
```
모바일:      max-width 767px
태블릿:      max-width 1023px
데스크탑:    min-width 1024px
와이드:      min-width 1600px
최대 너비:   1600px (--container-max)
```
> SoT: `.cursor/sot/05-design-tokens.md` §6~7

### 4-7. 아이콘
- **원본 저장소:** 레포 루트 **`_icons/`** (공용 SVG 풀)
- **납품 테마:** 사용 아이콘만 **`assets/icons/`로 복사** 후 참조 · `_icons/` 런타임 직접 링크 금지
- Lucide / Heroicons CDN **기본 사용 금지** (혼용·외부 의존 방지)
- 크기: 토큰 마스터 `--icon-xs`(14) / sm(16) / md(20) / lg(24) / xl(32) / 2xl(40)
- 라인 아이콘과 필드 아이콘 혼용 금지
- 같은 화면에서는 한 패밀리 스타일 유지

## 5. 모션 라이브러리

### 5-1. 스택 (필요할 때만)
- **모션이 필요할 때** 승인 표준: GSAP + ScrollTrigger (다른 모션 라이브러리 혼용 금지)
- **슬라이더가 필요할 때** 승인 표준: Swiper.js
- 모션·슬라이더가 없으면 GSAP/Swiper를 **의무로 넣지 않는다**

### 5-2. 기본 사용 기준 (모션을 쓰는 경우)
```
스크롤 진입: fade-up, duration 0.6s
카드 stagger: 0.1s 간격
모바일: 틸트, 패럴랙스, 커서 효과 전부 비활성화
히어로: 강한 효과 1개만
일반 섹션: 페이드업 기본 + 포인트 1개
```

### 5-3. 인터랙션 카테고리

**스크롤 효과**
- 페이드업 (범용)
- 좌우 슬라이드인 (텍스트+이미지 2단)
- 숫자 카운트업 (실적 섹션)
- 패럴랙스 배경

**텍스트 효과**
- 타이핑 효과
- 텍스트 마스크 리빌
- 글자 순차 등장
- 숫자 롤업

**호버 효과**
- 카드 리프트 (translateY + shadow)
- 버튼 슬라이드 필
- 이미지 줌인
- 틸트 효과 (데스크탑만)

**슬라이더**
- 로고 무한 슬라이드
- 후기/카드 슬라이더
- 비포/애프터 슬라이더

**UI 인터랙션**
- 아코디언
- 탭 전환
- 라이트박스 갤러리
- 스크롤 진행바

### 5-4. 인터랙션 강도 등급
- **기본**: 페이드업만
- **표준**: 페이드업 + 호버효과
- **프리미엄**: 표준 + 패럴랙스 + 커스텀 커서

### 5-5. 파일 구조
```
motion/
  text.js       타이핑, 마스크리빌, 글자등장
  scroll.js     페이드업, 카운트업, 패럴랙스
  hover.js      카드리프트, 버튼필, 틸트
  slider.js     무한슬라이드, 비포애프터
  ui.js         아코디언, 탭, 라이트박스
```

## 7. 납품 프로세스

### 7-1. 주문 확정 후 즉시
- 고객 자료 체크리스트 발송

**받아야 할 자료**
```
□ 로고 파일 (AI, PNG 투명배경)
□ 대표 사진 (고해상도)
□ 회사 소개 텍스트
□ 서비스/제품 목록
□ 원하는 레퍼런스 사이트 2~3개
□ 카페24 계정 정보 (또는 신규 가입 안내)
□ 도메인 정보
□ 대표 전화번호, 주소, 사업자 정보
□ 카카오톡 채널 링크 (있는 경우)
□ 워드프레스 관리자 사용 교육 필요 여부
□ 게시판/블로그 필요 여부 (플러그인·CPT 추가 여부)
```

### 7-2. 크몽 서비스 상세페이지 필수 명시 항목
```
□ 수정 횟수 (예: 3회 이내)
□ 제작 페이지 수
□ 텍스트/이미지 제공 주체
□ 납기 기준 (작업 시작일 vs 자료 수령일)
□ 유지보수 포함 여부
□ 추가 기능 요청 시 별도 견적
```

### 7-3. 납품 전 자체 점검 체크리스트

**레이아웃**
```
□ 모바일/태블릿/데스크탑 세 가지 확인
□ 사파리에서 깨지는 곳 없는지
□ 스크롤 시 겹치거나 튀는 요소 없는지
```

**타이포**
```
□ 본문 최소 **16px** (PC·모바일) · 캡션 **12px** · CTA **14px** · 제목 **20px** · input **16px**
□ 줄간격 1.5 이상
□ 텍스트 대비 4.5:1 이상 (WCAG AA)
```

**이미지**
```
□ 모든 이미지 alt 텍스트
□ 느린 네트워크에서 로드 확인
□ 비율 깨진 이미지 없는지
□ WebP 포맷 적용
```

**인터랙션**
```
□ 모바일에서 hover 효과 비활성화
□ 애니메이션 반복 재생 없는지
□ 버튼 클릭 피드백 있는지
```

**콘텐츠**
```
□ 히어로에서 3초 안에 뭐하는 곳인지 읽히는지
□ CTA 문구가 동사로 시작하는지
□ 사업자 정보 푸터에 있는지
□ 대표 전화번호 헤더에 있는지
□ 카카오톡 버튼 — 합의된 핵심 페이지(메인·문의 등)에 있는지 (전 페이지 강제 아님)
```

### 7-4. 납품 시 함께 제공
- 카페24 관리자 간단 안내문
- **워드프레스 관리자 사용 가이드** (페이지·이미지·게시글)
- 플러그인 업데이트 주기 · 백업 확인 방법
- 포트폴리오 활용 동의 여부 확인

### 7-5. 게시판·소식
- 공지/소식 구현 방식(**미결정**): WP 기본 **글** vs CPT(`notice` 등) vs **동반 플러그인**  
  → 확정·승인 전 테마에 임의 구현하지 않는다
- Q&A·문의: Contact Form 7 등 (델타·TRANSITION)
- 방문자 자유게시판·회원 기능은 **기본 범위 제외**

## 8. 아직 논의 필요한 사항

### 8-0. 소식/공지 CMS 구현 (미정)
- 기본 글 / `notice` CPT / 동반 플러그인 분리 중 선택
- 선택 전 테마·functions에 CPT 임의 등록 금지

### 8-1. 가격 책정 (미정)
- 제작 기본 단가
- 유지보수 월 단가
- 수정 초과 시 추가 단가
- 패키지 구성 및 가격

### 8-2. 첫 주문 전략 (미정)
- 포트폴리오 완성 후 어떻게 첫 후기를 만들지
- 지인 활용 여부
- 초기 가격 전략

### 8-3. 시작 업종 선택 (미정)
- 어떤 업종부터 포트폴리오를 만들지
- 기준: 본인이 그 업종 사람들과 대화하기 편한 곳

### 8-4. 커서 지침 실제 검증 (진행 중)
- 토큰, 모션 라이브러리, 컴포넌트 규칙이 실제 커서에서 얼마나 잘 작동하는지
- 첫 포트폴리오 제작하면서 동시에 검증 예정

### 8-5. 포트폴리오 수량 목표 (미정)
- 크몽 등록 전 최소 몇 개가 필요한지
- 업종별 몇 개씩 만들지
