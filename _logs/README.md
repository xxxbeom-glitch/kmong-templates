# Logs Usage

`_logs/`는 작업 기록 저장소이자 **다음 작업을 위한 기억 장치**다.

## 기본 원칙

- 작업 **시작 전** 관련 로그를 먼저 확인한다.
- 작업 **종료 후** 변경/QA/실패/결정 사항을 기록한다.
- 같은 실수와 오판단이 반복되지 않도록 QA FAIL, 보류, 사용자 승인 내용을 남긴다.
- 로그는 전체를 매번 정독하지 않고, **해당 템플릿·직전 섹션·최근 결정** 중심으로 확인한다.

## 파일 역할

| 파일 | 용도 |
|------|------|
| `decision-log.md` | 프로젝트·템플릿 확정 결정 |
| `change-log.md` | 변경 파일, 미구현, 확정 기준 |
| `qa-log.md` | QA PASS/FAIL, 비고, 주의점 |
| `failure-log.md` | 미해결 실패, 재발 방지 |

## 기록 항목 템플릿

각 섹션 작업 기록에는 가능하면 아래 항목을 남긴다.

- 날짜
- 템플릿 slug
- 대상 섹션
- Figma frame / node-id
- 수정 파일
- MCP 기준 수치 요약
- 구현 요약
- QA 결과: PASS / FAIL
- 사용자 승인 여부
- 미해결 이슈
- 다음 작업 시 주의점
