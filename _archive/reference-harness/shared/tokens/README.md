# Shared tokens (Tenfold SoT · 초기)

초기 범위만 둔다. **`01-original` · `04-working-copy`에는 적용하지 않는다.** **`06-normalized`**부터 사용.

| 파일 | 내용 |
|------|------|
| `typography.css` | SUIT CDN·타입 스케일 |
| `colors.css` | 컬러 역할 (text / muted / accent / bg / surface / border) |
| `spacing.css` | 간격 스케일 |
| `layout.css` | 컨테이너·gutter 최대폭 |
| `radii.css` | radius |
| `buttons.css` | primary / ghost 버튼 |
| `motion.css` | duration · easing |

reconstruction에 normalized 토큰을 선적용하면 **PASS 금지** (`reconstruction.md` §7).

값는 파일럿 중 보강한다. 확정본은 여기만 수정한다.
