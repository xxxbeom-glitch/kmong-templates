# Deployment Checklist

## 업로드 전

- [ ] 운영 디자인 백업
- [ ] 테스트 디자인 준비 (신규/복제)
- [ ] 원본 스킨(project original SoT) 보관 확인
- [ ] upload package 무결성 확인
- [ ] 보안 정보 제외
- [ ] 누락 자산 확인
- [ ] 변경 파일 목록 확인

## 테스트 디자인 업로드

- [ ] HTML 업로드
- [ ] CSS 업로드
- [ ] JavaScript 업로드
- [ ] 이미지 업로드
- [ ] 폰트 업로드 (참조되는 것만)
- [ ] 관리자 설정 확인 (`ADMIN_CHECK_REQUIRED` 해소)

## 기능 QA

- [ ] 메인
- [ ] 상품 목록
- [ ] 상품 상세
- [ ] 상품 옵션
- [ ] 장바구니
- [ ] 로그인
- [ ] 회원가입
- [ ] 마이페이지
- [ ] 주문서
- [ ] 결제 직전 단계
- [ ] 쿠폰
- [ ] 배송지
- [ ] 게시판
- [ ] 기능 팝업 / 하루 닫기 (`_archive/docs/cafe24/popup-rules.md`)
- [ ] 모바일

## 운영 전환

- [ ] 테스트 디자인 최종 확인
- [ ] 대표 디자인 변경 **승인** (별도)
- [ ] 전환 시각 기록
- [ ] 운영 화면 확인
- [ ] rollback package 준비
