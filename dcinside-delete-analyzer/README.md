# DCInside 게시글·댓글 삭제 도구

갤로그 **게시글(`/posting`)** · **댓글(`/comment`)** 페이지에서  
본인 항목을 선택·테스트·전체 순차 삭제하는 Chrome Manifest V3 확장프로그램입니다.

> 사이트의 원래 X 삭제 버튼을 `click()` 합니다.  
> 직접 POST / `c_k_v`·`ci_t` 추출은 사용하지 않습니다.  
> **테스트 5개 삭제**로 먼저 확인하세요.

---

## 설치

1. `chrome://extensions` → 개발자 모드 ON  
2. **압축해제된 확장 프로그램을 로드합니다**  
3. 이 폴더 선택 후, 수정 시 **확장·갤로그 탭 새로고침**

---

## 게시글 / 댓글 탭

팝업 상단 **[게시글] [댓글]** 탭으로 전환합니다.  
탭을 누르면 현재 갤로그 ID의 `/posting` 또는 `/comment`로 이동합니다.  
URL에 `/posting`·`/comment`가 있으면 자동으로 모드를 맞춥니다.

---

## 삭제 방식 (공통)

1. 목록 행의 원래 `button.btn_delete.btn_listdel` (또는 동등 버튼) `click()`  
2. 자동화 중에만 삭제 confirm 자동 승인  
3. 사이트 JS가 삭제 처리 → 페이지 새로고침  
4. `chrome.storage.local`로 다음 항목 이어가기  

전체 삭제: 항상 **첫 행**의 X를 반복 클릭합니다.  
목록이 비었는데 전체 수가 남아 있으면 다음 페이지 링크를 탐색합니다.

---

## 댓글 테스트 5개

1. 댓글 탭 또는 `/comment` 페이지 접속  
2. 팝업 → **테스트 5개 삭제**  
3. “댓글 5개를 실제로 삭제합니다…” 확인  
4. 정확히 5개 후 자동 완료  

---

## 안전 확인

| 작업 | 확인 |
|------|------|
| 게시글 전체 삭제 | 1차 확인 + `전체삭제` 입력 |
| 댓글 전체 삭제 | 1차 확인 + `댓글전체삭제` 입력 |

---

## 자동 중지

- 삭제 버튼 미발견  
- 15초 내 새로고침 없음  
- 연속 3회 실패  
- 로그인/비지원 페이지 이동  
- 동일 대상 반복(무한 루프)  
- 사용자 중지
