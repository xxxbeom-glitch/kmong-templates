# Rollback Plan

## 롤백 기준

- 주요 화면 렌더 오류
- 상품 옵션 동작 실패
- 장바구니 실패
- 로그인·회원가입 실패
- 주문서 오류
- JavaScript 전역 오류
- 이미지·CSS 대량 누락

## 롤백 대상

- 이전 대표 디자인
- 이전 HTML / CSS / JavaScript / 이미지 자산
- rollback package 경로: `_release/{slug}/rollback/`

## 롤백 방식 (구분)

### A. 대표 디자인 전환 복구

카페24 관리자에서 **이전 production design을 다시 대표**로 지정.  
파일 업로드보다 우선 검토 (전환만으로 복구 가능한 경우).

### B. 파일 단위 복구

변경·손상 파일만 rollback package에서 test/운영 디자인으로 재업로드.  
삭제했던 파일 복원 순서 기록.
